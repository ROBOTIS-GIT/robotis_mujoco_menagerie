# Published simulation evidence

The baseline folder contains eight successful closed-loop simulation trials,
metrics, plots, parameter metadata, code snapshots and trace hashes. The Part C
folder contains nine-setting replay comparisons and two separate fresh candidate
closed-loop checks. They must not be pooled into one navigation success count.

Large JSON traces are stored as `.json.gz`. Source snapshots are archived as
`source-snapshot.zip` beside their SHA-256 manifests. Derived replay series are
regenerated by `study_ekf.py` rather than duplicated here. Expand them from the repository root:

```sh
python3 robotis_tb3/unpack_evidence.py
.venv/bin/python robotis_tb3/study_ekf.py robotis_tb3/evidence/baseline part-c-replay-output
.venv/bin/python robotis_tb3/plot_ekf_study.py part-c-replay-output
```

Install runtime/analysis dependencies with `requirements-analysis.txt`. Plots in
this folder were resized for GitHub display; raw numerical evidence is retained.
Output paths in JSON run metadata were made repository-relative for portability.
Recorded trace contents are preserved under gzip, so the input hashes in the
Part C selection file can be verified after decompression.

Review [baseline results](baseline/Evaluation-summary.txt), [Part C write-up](../PART_C_ESTIMATION.md),
[study summary](part-c/study-summary.json), [tuning comparison](part-c/tuning-comparison.png)
and [uncertainty comparison](part-c/uncertainty-validation.png).

These are small correlated simulation samples, not evidence of perfect tuning,
hardware calibration, a guaranteed grade, or a finished assessment submission.

## Part D

`part-d/eval_cmp/` holds the 80-trial heuristic-versus-LQR comparison (`summary.json`, `controller_results.md`, `tracking_boxplot.png`);
the tables in `PART_D_CONTROL.md` Section 4 are generated from that `summary.json` by `lqr/part_d_summary.py`. `part-d/tracking_lqr_nominal_seed0.png`
is a single-trial figure from an earlier run. The actuator-identification and compensation files in `part-d/` are open-loop bench results,
not closed-loop trials. Large per-trial traces were not committed.
